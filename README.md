# Hospitality-Revenue-Dashboard
"Power BI dashboard analyzing hotel revenue across 4 cities"
## Revenue Insights in Hospitality Domain

### Tools Used
Power BI, DAX, Power Query

### Problem Statement
Analysed hotel booking data to identify revenue trends and property performance across cities.

### Key Insights
- Total Revenue: $1.7Bn across 1,34,590+ bookings
- Top property: Atliq Exotica Mumbai with $21M+ revenue
- Occupancy Rate: 57.87% overall
- Premium room class contributed highest revenue (462M)
